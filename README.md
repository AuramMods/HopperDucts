# Hopper Ducts for Forge 1.12.2

FyberOptic's Hopper Ducts v1.5, reconstructed from `hopperducts-mc1.12-1.5.jar`
with Vineflower 1.12.0 and MCP stable 39 mappings. The original assets and
[release README](src/main/resources/README.txt) are included.

The input JAR has SHA-256
`73c47bdcc766f5c978c3606cd2901ffb9f07fceb59c989a39709c900455ff31b`.

## Build

With JDK 8, run `./gradlew build` (`gradlew.bat build` on Windows). The Gradle
wrapper builds for Forge 14.23.5.2864 and writes the reobfuscated mod to
`build/libs/hopperducts-1.5.jar`.
